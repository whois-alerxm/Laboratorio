Conversor de Unidades

Este proyecto es una aplicación web sencilla para convertir unidades de medida en diferentes categorías, como velocidad, energía, peso, temperatura y distancia.

Estructura del Proyecto

El proyecto consta de los siguientes archivos principales:

index.html - Contiene la estructura básica de la página web.

styles.css - Archivo de estilos para mejorar la apariencia visual.

script.js - Contiene la lógica de conversión de unidades.

Categorías de Conversión

El conversor permite convertir entre las siguientes unidades:

Velocidad: km/h ↔ m/s

Energía: Joules ↔ Calorías

Peso: Kilogramos ↔ Libras

Temperatura: Celsius ↔ Fahrenheit

Distancia: Kilómetros ↔ Millas

Uso

Seleccionar una categoría en el menú desplegable.

Ingresar un valor en el campo de entrada.

Hacer clic en el botón "Convertir" para obtener el resultado.

Requisitos

Solo se necesita un navegador web moderno para ejecutar el conversor.
